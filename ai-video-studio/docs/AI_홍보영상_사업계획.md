# AI 홍보영상 제작사업 — 사업 계획 (① 단계)

> 상태: **확정 (2026-11-23)**. 상호만 정하면 끝납니다.
> 확정한 내용: 가게 업종 4가지, 하루 3~4시간, 높은 가격, AI 도구 써 본 경험 있음
> 보험 관련 영상은 받지 않습니다.
> 이 저장소는 공개되어 있으니 고객 이름·연락처는 적지 않습니다.

---

## 1. 타깃 고객 (두 갈래)

| 구분 | 누구 | 왜 돈을 내나 | 역할 |
|---|---|---|---|
| **A. 기업** | 중소기업·제조업·지역 회사 CEO | 회사 소개, 제품 홍보, 채용, 전시회 영상이 필요한데 촬영 업체는 비쌈(300~1,000만 원) | **1편 단가가 큼** (큰돈) |
| **B. 동네 가게** | ① 음식점·카페 ② 미용실·네일·피부관리 ③ 병원·한의원·치과 ④ 학원·헬스장·필라테스 | 인스타·쇼츠·네이버 플레이스에 영상을 꾸준히 올려야 손님이 오는데 직접 만들 시간이 없음 | **매달 들어오는 돈** (월 구독) |

- 대표님의 30년 영업 인맥(자영업자·CEO)으로 **첫 고객은 아는 분 소개**로 시작합니다.
- 업종마다 **영상 틀(템플릿)**을 하나씩 만들어 두고 고객마다 바꿔 씁니다. 그래야 하루 3~4시간으로 됩니다.
- 병원·한의원·치과는 **의료광고 심의** 대상입니다. 치료 효과 보장, 전후 사진, 환자 후기는 쓰지 않고, 정보 전달형으로 만듭니다.

## 2. 상품과 가격 (높은 가격으로 확정)

| 상품 | 내용 | 가격 | 작업 시간(익숙해진 뒤) |
|---|---|---|---|
| **① 맛보기 쇼츠** | 15~30초 세로 영상 1편, 기획안·자막·음악·나레이션, 수정 1회, 3일 납품 | **35만 원** | 2시간 |
| **② 가게 월 구독 베이직** | 쇼츠 4편/월 + 썸네일 + 게시글·해시태그, 수정 각 1회 | **월 69만 원** | 월 7시간 |
| **③ 가게 월 구독 플러스** | 쇼츠 8편/월 + 업로드 대행 + 월말 반응 보고 | **월 119만 원** | 월 13시간 |
| **④ 기업 브랜드 영상** | 60~120초 회사·제품 소개 + 쇼츠 3편으로 잘라 드림, 수정 2회, 7~10일 | **200만 원** | 12시간 |
| **⑤ 기업 프리미엄** | ④ + 현장 사진·영상 활용, 성우급 나레이션, 영문 자막 | **330만 원~** | 20시간 |

**높은 가격을 받으려면 (꼭 지킬 것)**
- 영상만 주지 말고 **기획안을 먼저 보여 드립니다.** "생각을 정리해 주는 사람"이라는 느낌이 가격을 만듭니다.
- 샘플 영상 품질이 가장 중요합니다. ② 단계에서 샘플을 공들여 만듭니다.
- 가격을 깎아 주는 대신 **덤을 드립니다.** (쇼츠 1편 추가, 썸네일 추가 등)

**거래 규칙**
- 계약금 50%, 납품 때 잔금 50%. 구독은 매달 미리 받습니다.
- 수정 횟수는 상품에 적힌 만큼만 하고, 더 하면 1회 5만 원입니다.
- 첫 고객 3곳은 정가를 받되 덤을 드리고, 대신 후기와 샘플 공개 허락을 받습니다. (가격을 한번 낮추면 올리기 어렵습니다)

## 3. 월 1,000만 원 만드는 조합 (하루 3~4시간 기준)

| 상품 | 건수 | 매출 | 작업 시간 |
|---|---|---|---|
| ④ 기업 브랜드 영상 200만 원 | 3건 | 600만 원 | 36시간 |
| ② 가게 구독 베이직 69만 원 | 5곳 | 345만 원 | 35시간 |
| ① 맛보기 쇼츠 35만 원 | 2건 | 70만 원 | 4시간 |
| **합계** | | **1,015만 원** | **75시간** |

- 75시간 ÷ 한 달 일하는 날 21일 = **하루 약 3.5시간** → 대표님 시간에 맞습니다.
- 들어가는 돈(AI 도구 구독): 한 달 약 20~30만 원 → **남는 돈 약 985만 원** (세금 별도)
- 처음 2달은 익숙하지 않아 시간이 2배쯤 걸립니다. 그래서 1~2달째 목표를 낮게 잡았습니다.
- **기업 영상 3건이 핵심**입니다. 대표님의 CEO 인맥이 여기서 힘을 냅니다.
- 기업 영상 대신 가게 구독이 늘면: 구독 10곳(690만 원) + 기업 2건(400만 원) = 1,090만 원, 약 94시간

## 4. 쓸 AI 도구 (처음엔 최소로)

| 하는 일 | 도구 (예시) | 비용 |
|---|---|---|
| 기획·대본 | Claude 또는 ChatGPT | 월 약 3만 원 |
| 이미지 | Midjourney, 나노바나나, ChatGPT 이미지 중 1개 | 월 1.5~4만 원 |
| 이미지 → 영상 | Kling 또는 Hailuo (처음엔 1개만) | 월 1~10만 원 (쓰는 만큼) |
| 목소리(나레이션) | 타입캐스트 또는 ElevenLabs | 월 1~3만 원 |
| 편집·자막 | 캡컷(쉬움), Vrew(자동 자막) | 무료~월 2만 원 |
| 배경음악 | 상업용으로 써도 되는 음원 사이트 | 무료~월 2만 원 |

> 도구 가격은 자주 바뀝니다. 가입 전에 그 사이트에서 다시 확인하세요.
> 처음 2주는 **무료 체험 위주로** 써 보고 손에 맞는 것만 유료로 바꿉니다.

## 5. 8주 시작 계획

| 주 | 할 일 | 끝나면 생기는 것 |
|---|---|---|
| 1주 | 도구 가입·연습, 사업자 등록·겸업 규정 확인, 상호 정하기 | 작업 준비 완료 |
| 2주 | **샘플 영상 4편** 만들기 (음식점·카페 쇼츠, 미용실 쇼츠, 헬스장·학원 쇼츠, 기업 소개 1편) → **② 단계** | 포트폴리오 |
| 3주 | 포트폴리오 페이지, 카카오톡 채널, 견적표 | 보여 줄 곳 |
| 4주 | 인맥 30명에게 연락, 첫 고객 3곳은 할인 대신 덤(쇼츠 추가)으로 받기 | 첫 매출 |
| 5~6주 | 유료 주문 3~5건, 후기 받기 | 후기·실제 사례 |
| 7~8주 | 맛보기 고객을 월 구독으로 바꾸기, 소개 부탁하기 | 매달 들어오는 돈 |

## 7. 조심할 점과 대비책

| 위험 | 대비책 |
|---|---|
| "AI 티 난다"는 반응 | 고객 매장·제품의 **실제 사진을 섞어서** 만듭니다. 처음 3초 훅과 자막 품질에 신경 씁니다. |
| 수정 요청이 끝없이 옴 | 수정 횟수를 계약서에 적고, 기획안을 미리 확인받은 뒤 제작합니다. |
| 돈을 못 받음 | 계약금 50%를 먼저 받습니다. |
| 저작권·초상권 | 상업용 음원·폰트만 쓰고, 실존 인물·남의 로고는 쓰지 않습니다. 고객 얼굴이 나오면 동의를 받습니다. |
| 광고 규정 | 병원(의료광고 심의), 건강식품, 부동산 광고는 과장 표현을 확인합니다. |
| 겸업·세금 | 지금 다니는 회사의 겸업 규정을 확인하고, 사업자 등록과 부가세 신고를 합니다. |
