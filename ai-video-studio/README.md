# 🎬 AI 영상 스튜디오

AI 홍보영상 제작사업(목표 월 1,000만 원)의 업무 자동화 프로그램입니다.
영업비서 앱과는 **따로** 동작합니다. 화면 파일, 앱 설치 정보, 아이콘, 데이터 저장 공간이 모두 따로 있습니다.

## 할 수 있는 일

| 화면 | 기능 |
|---|---|
| 🏠 홈 | 이번 달 받은 돈과 1,000만 원 달성률, 구독 고객 수, 매달 고정 매출, 미수금, 오늘 할 일, 이번 달 구독 영상 진행, 6개월 매출 그래프, 목표까지 필요한 건수 |
| 🎬 기획 만들기 | 업종·상호·강점 등을 넣으면 **콘셉트 3안, 훅 5개, 장면별 구성(자막·나레이션·이미지/영상 AI 프롬프트), 음악·목소리, 해시태그, 게시글 2개, 광고 규정 주의**를 자동으로 만듭니다. 고객용 / 작업용 복사, 파일 받기, 저장, Claude·ChatGPT용 프롬프트 복사 |
| 📋 주문 | 고객·상품·금액·마감일, 진행 단계(상담→견적→계약금→기획→제작→수정→납품→완료), 받은 돈 기록(계약금·잔금·구독료 버튼), 월 구독 편수 체크, **견적서**(카톡 복사·인쇄/PDF) |
| ⚙️ 설정 | 상호·대표자·연락처·계좌, 월 목표, 상품·가격표 고치기, 백업 내보내기/불러오기, 밝게/어둡게 |

업종: 음식점·카페 / 미용실·네일·피부관리 / 병원·한의원·치과 / 학원·교습소 / 헬스장·필라테스 / 기업·제조업 (보험 분야 제외)

## 자동화 방식
- 외부 AI로 정보를 보내지 않습니다. 업종별 문구 틀과 장면 자료로 앱 안에서 바로 만들기 때문에 **무료**입니다.
- 더 다양한 결과가 필요하면 **🤖 AI에게 보낼 프롬프트 복사**를 눌러 Claude·ChatGPT에 붙여넣습니다.
- 나레이션은 1초에 6글자를 기준으로 길이를 확인합니다.
- 업종별 문구 틀은 `index.html`의 `IND`(업종 자료), `STRENGTH_SHOTS`(강점 → 장면), `MOODS`(분위기)에서 고칩니다.

## 데이터
- 이 기기 브라우저 안(`aivs_studio_v1`)에만 저장됩니다. 인터넷에 올라가지 않습니다.
- 기기를 바꿀 때는 ⚙️ 설정 → 백업 내보내기/불러오기를 씁니다.
