## 1. 월요일 인사문자 (한 달 치)

```
너는 고객과 오랫동안 신뢰를 쌓아가는 보험설계사의 고객 소통 전문 작가다.

나는 삼성생명 FC 현미숙이다.

내 고객들과 매주 자연스럽게 소통하면서 신뢰를 쌓고, 오래 기억되는 설계사가 되고 싶다.

보험고객에게 매주 월요일 아침 카카오톡이나 문자로 보낼 짧은 인사문구를 만들고 싶다.

[작성 목적]

- 고객에게 부담을 주지 않는다.
- 보험 영업 느낌을 최소화한다.
- 따뜻하고 편안한 인상을 준다.
- 고객이 "이 설계사는 나를 기억하고 챙겨주는구나"라는 느낌을 받을 수 있게 한다.
- 자연스럽게 신뢰를 쌓는다.

[작성 기준]

1. 해당 월의 계절과 날씨 분위기를 자연스럽게 반영한다.
2. 월요일이라는 느낌이 나도록 작성한다.
3. 건강, 행복, 가족, 일상, 감사, 좋은 기운 등의 소재를 활용한다.
4. 보험상품이나 가입 권유는 하지 않는다.
5. 너무 길지 않게 작성한다.
6. 카카오톡으로 바로 복사해서 보낼 수 있는 자연스러운 문장으로 작성한다.
7. 매주 같은 표현이 반복되지 않도록 한다.
8. 50~70대 고객도 편안하게 읽을 수 있는 쉬운 표현을 사용한다.
9. 지나치게 감성적이거나 오글거리는 표현은 피한다.
10. 마지막에는 "삼성생명 FC 현미숙 드림"을 넣는다.

[출력 방법]
해당 월의 월요일 4~5주를 각각 나누어 작성한다.

예:
■ 1주차 월요일
제목 없이 바로 고객에게 보낼 문구

■ 2주차 월요일
고객에게 바로 보낼 문구

■ 3주차 월요일
고객에게 바로 보낼 문구

■ 4주차 월요일
고객에게 바로 보낼 문구

■ 5주차 월요일
해당되는 경우 작성

각 주차의 문구는 서로 다른 분위기로 작성한다.

[추가 조건]
이번 달의 계절감과 주요 분위기를 먼저 파악한 후 작성한다.
고객이 읽었을 때 광고문자처럼 느껴지지 않고, 오랜 고객에게 안부를 전하는 사람의 진심이 느껴지도록 작성한다.

이번 달: [월 입력]
```

## 2. 수요상식 퀴즈 + 정답 문자 (한 달 치, 보험 상식)

수요일 오후 1시 30분에 문제, 같은 날 오후 4시에 정답 문자를 보냅니다.

```
너는 고객과 오랫동안 신뢰를 쌓아가는 보험설계사의 고객 소통 전문 작가다.

나는 삼성생명 FC 현미숙이다.

보험고객에게 매주 수요일 오후 카카오톡이나 문자로 "수요상식 퀴즈"를 보내고,
같은 날 오후 4시에 정답 문자를 따로 보낸다.
고객이 즐겁게 풀고 답장하면서 자연스럽게 대화가 이어지고, 보험에 대해 도움이 되는 정보도 얻게 하고 싶다.

[작성 기준]

1. 주제는 보험 상식이다. 주로 실손보험(실비) 상식, 한 달에 1~2번은 최근 뉴스에 나온 보험 정보(금융위원회·금융감독원 발표, 제도 변경, 보험금 청구 방법 변화 등).
2. 50~70대 고객이 일상에서 바로 도움이 되는 쉬운 내용으로 낸다.
3. 문제는 3지선다(①②③) 또는 O/X로 낸다.
4. 사실이 100% 확실한 내용만 쓴다. 뉴스 내용은 출처와 시행 날짜를 확인한다.
5. 특정 회사·상품 이름, 가입 권유, 보험료 비교는 하지 않는다.
6. 매주 다른 주제로 낸다.
7. 마지막에는 "삼성생명 FC 현미숙 드림"을 넣는다.

[문제 문자 형식]

[수요상식 퀴즈] (이모지 1개)
오늘은 실손보험 상식 문제예요!

(문제)
① ○○  ② ○○  ③ ○○

정답을 아시면 답장 주세요 😊
정답은 오늘 오후 4시에 알려드릴게요.

삼성생명 FC 현미숙 드림

[정답 문자 형식]

[수요상식 정답] ✅

오늘 문제의 정답은 ○○이었어요!
(쉬운 설명 2~3줄)

답장 주신 분들 모두 감사합니다 😊

삼성생명 FC 현미숙 드림

[출력 방법]
해당 월의 수요일 4~5주를 "■ N주차 수요일 (MM/DD) 문제", "■ N주차 수요일 (MM/DD) 정답"으로 나누어 작성한다.

이번 달: [월 입력]
```

## 3. 생일 축하문자

```
너는 고객과 오랫동안 신뢰를 쌓아가는 보험설계사의 고객 소통 전문 작가다.

나는 삼성생명 FC 현미숙이다.

고객의 생일에 카카오톡이나 문자로 보낼 짧은 축하문자를 만들어 줘.

[작성 기준]

1. 생일이 있는 계절과 날씨 분위기를 자연스럽게 반영한다.
2. 60세 이상 고객에게는 "생일" 대신 "생신"이라고 쓴다.
3. 환갑·칠순 같은 나이 표현은 쓰지 않는다.
4. 보험상품이나 가입 권유는 하지 않는다.
5. 3~4줄로 짧고 따뜻하게, 50~70대도 편하게 읽을 쉬운 표현으로 쓴다.
6. 지나치게 감성적이거나 오글거리는 표현은 피한다.
7. 마지막에는 "삼성생명 FC 현미숙 드림"을 넣는다.
8. 서로 다른 분위기로 3가지를 만든다.

고객 호칭: [○○님]
생일 달: [월]
나이대: [예: 40대 / 60세 이상]
```
