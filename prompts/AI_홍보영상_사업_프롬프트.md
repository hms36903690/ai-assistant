# AI 홍보영상 제작사업 — 프롬프트 모음 (목표: 월 1,000만 원)

AI(Claude, ChatGPT 등)에게 그대로 복사해서 쓰는 지시문 모음입니다. `[ ]` 부분만 바꿔서 쓰면 됩니다.
1번은 사업 전체를 같이 설계하는 프롬프트, 2~5번은 실제 일할 때 쓰는 프롬프트,
6번은 이 일을 자동으로 돕는 **프로그램(앱)을 만드는 프롬프트**입니다.

> 이 저장소는 공개되어 있습니다. 이 파일에는 **고객 정보·가격 협상 내용·비밀번호를 적지 마세요.**

---

## 0. 월 1,000만 원 숫자 계산 (먼저 감 잡기)

| 상품 | 가격(예시) | 한 달 목표 | 매출 |
|---|---|---|---|
| ① 쇼츠 1편 (15~30초, 세로) | 30만 원 | 8건 | 240만 원 |
| ② 홍보영상 1편 (60~90초, 가로+세로) | 80만 원 | 4건 | 320만 원 |
| ③ 월 구독 (쇼츠 4편/월 + 썸네일 + 올리기 대행) | 월 55만 원 | 8곳 | 440만 원 |
| **합계** | | | **1,000만 원** |

- 핵심은 **③ 월 구독**입니다. 한 번 팔고 끝나는 영상보다, 매달 들어오는 고객 8~10곳이 생기면 안정됩니다.
- 처음 2~3달은 포트폴리오(샘플) 만들기 + 아는 분 소개로 시작하고, 4~6달째에 1,000만 원을 목표로 잡는 게 현실적입니다.
- 가격·건수는 예시입니다. 1번 프롬프트로 내 상황에 맞게 다시 계산합니다.

## 1. 사업 설계 마스터 프롬프트 (처음 한 번, 크게 그리기)

```
너는 1인 AI 영상 제작사를 월 매출 1,000만 원까지 키워 본 사업 코치이자 마케팅 전문가다.
나는 AI 홍보영상 제작사업을 새로 시작하려고 한다. 개발·영상 편집 지식은 많지 않으니 쉬운 말로 설명해 줘.

[내 상황]
- 하루에 쓸 수 있는 시간: [예: 평일 저녁 3시간, 주말 6시간]
- 지금 하는 일 / 인맥: [예: 보험설계사 30년, 자영업자·CEO 고객 인맥 많음]
- 첫 달 쓸 수 있는 돈(AI 도구 구독 등): [예: 월 15만 원]
- 잘하는 것: [예: 상담, 글쓰기, 사람 만나기]
- 목표: 6개월 안에 월 순수익 1,000만 원

[만들어 줄 것]
1. 타깃 고객 TOP 5 — 돈을 낼 이유가 확실하고 내 인맥으로 닿을 수 있는 업종 (이유, 예상 단가 포함)
2. 상품 구성 3단계 (입문 / 주력 / 월 구독) — 이름, 포함 내용, 가격, 작업 시간, 남는 돈
3. 월 1,000만 원 달성 표 — 상품별 몇 건이 필요한지, 하루에 몇 시간 일해야 하는지
4. 필요한 AI 도구 목록 — 이미지·영상·목소리·자막·편집, 무료/유료, 한 달 비용 합계
5. 첫 고객 10명 잡는 방법 — 1주차~8주차 할 일 표
6. 6개월 로드맵 — 월별 목표 매출·고객 수·해야 할 일
7. 조심할 점 — 저작권·초상권·AI 생성물 표시·광고 심의·세금(사업자등록), 겸업 규정 확인

[규칙]
- 막연한 말 말고 숫자와 표로 보여 줘.
- 장밋빛 전망만 말하지 말고, 안 될 수 있는 이유와 대비책도 같이 적어 줘.
- 마지막에 나에게 꼭 물어봐야 할 질문 5개를 적어 줘.
```

## 2. 고객 상담 → 영상 기획안 만들기

```
너는 소상공인·전문직 홍보영상을 1,000편 넘게 기획한 광고 기획자다.
아래 고객 정보를 보고 "홍보영상 기획안"을 만들어 줘. 고객에게 바로 보여 줄 수 있게 깔끔하게.

[고객 정보]
- 업종 / 상호: [예: 동네 한의원 / ○○한의원]
- 지역: [예: 수원 영통]
- 주요 손님: [예: 30~50대 직장인, 허리·어깨 통증]
- 남들과 다른 점(강점): [예: 야간 진료, 주차 편함, 원장 20년 경력]
- 영상 쓰는 곳: [예: 인스타 릴스, 유튜브 쇼츠, 네이버 플레이스]
- 길이 / 비율: [예: 30초 / 세로 9:16]
- 분위기: [예: 따뜻하고 믿음 가는]
- 꼭 넣을 말 / 넣으면 안 되는 말: [예: 전화번호 / 과장된 치료 효과 금지]

[만들어 줄 것]
1. 영상 한 줄 콘셉트 (3가지 안 → 추천 1개와 이유)
2. 처음 3초 '훅' 문장 5개 (스크롤을 멈추게 하는 말)
3. 장면별 구성표: 장면 번호 | 초 | 화면에 보이는 것 | 자막 | 나레이션 | 배경음 분위기
4. 마지막 행동 유도 문구(CTA) 3개
5. 해시태그 15개, 게시글 본문 2가지
6. 법적으로 조심할 표현 체크 (의료·보험·금융·부동산 광고 규정)
```

## 3. 장면별 AI 생성 프롬프트 만들기 (이미지·영상·목소리)

```
너는 AI 영상 생성 전문가다. 아래 장면 구성표를 보고, 장면마다 AI 도구에 넣을 프롬프트를 만들어 줘.

[장면 구성표]
(2번에서 받은 표를 그대로 붙여넣기)

[쓰는 도구]
- 이미지: [예: Midjourney / 나노바나나 / ChatGPT 이미지]
- 영상(이미지→영상): [예: Kling / Runway / Veo / Hailuo]
- 목소리: [예: ElevenLabs / 타입캐스트 / 클로바더빙]
- 편집: [예: 캡컷 / Vrew]

[장면마다 만들어 줄 것]
1. 이미지 프롬프트 (영어) — 피사체, 배경, 조명, 카메라 각도, 렌즈, 색감, 비율(--ar 9:16 등)
2. 영상 움직임 프롬프트 (영어) — 카메라 움직임, 사람/사물 움직임, 길이(초)
3. 하지 말아야 할 것 (negative) — 글자 깨짐, 손가락 이상, 로고 왜곡 등
4. 나레이션 원고 (한국어, 초 수에 맞는 글자 수) + 목소리 톤 지시
5. 모든 장면의 인물·색감이 같아 보이게 하는 '공통 스타일 문장' 1개

[규칙]
- 실제 유명인·브랜드 로고·남의 캐릭터는 넣지 않는다.
- 고객 매장 실제 사진이 있으면 그 사진을 기준으로 쓰는 방법을 따로 알려 준다.
```

```

나는 AI 홍보영상을 만들어 주는 1인 제작사 [상호]를 운영한다.

[상대] [예: 동네 미용실 원장님, 50대, 인스타는 하지만 영상은 안 올림]
[내 상품] [예: 쇼츠 30만 원 / 월 구독 55만 원(쇼츠 4편)]
[샘플 링크] [포트폴리오 주소]

[만들어 줄 것]
1. 첫 카톡/DM 문구 3가지 (짧게, 영업 티 적게, 무료 샘플 1편 제안)

3. "비싸요" "생각해 볼게요" "AI 영상은 티 나지 않아요?" 에 대한 답변

```

## 6. 프로그램(앱) 만들기 프롬프트 — Claude Code용

이 사업을 돕는 나만의 프로그램 **'AI 영상 스튜디오 매니저'**를 단계별로 만듭니다.
아래를 통째로 복사해서 Claude Code에 붙여넣고, 맨 아래 `[이번에 만들 단계]`만 바꿉니다.

```
너는 내 1인 AI 홍보영상 제작사의 업무 프로그램을 만드는 개발자다.
나는 개발 지식이 많지 않으니 기술 용어는 쉽게 풀어서 설명해 줘.

[프로그램 이름] AI 영상 스튜디오 매니저
[형태] 휴대폰·PC 둘 다 되는 웹앱(PWA). 지금 쓰는 영업비서 앱과 같은 방식(GitHub Pages, 무료).

[전체 기능 — 단계별로 나눠서 만든다]
1단계 · 고객/주문 관리
  - 고객 등록(업종·연락처·채널), 주문 진행 단계: 상담 → 견적 → 계약금 → 기획 → 제작 → 수정 → 납품 → 잔금
  - 월 구독 고객은 이번 달 남은 편수 표시
2단계 · 기획안 자동 만들기
  - 상담 질문지를 채우면 기획안·장면 구성표·자막·나레이션 원고가 자동으로 나옴
  - 처음엔 앱 안의 문구 틀(무료)로, 나중에 원하면 AI API 연결
3단계 · 장면별 AI 프롬프트 생성기
  - 장면표 → 이미지/영상/목소리 도구별 프롬프트를 한 번에 복사
  - 업종별 템플릿(병원·학원·음식점·미용실·부동산·보험설계사 등) 저장
4단계 · 견적서·계약서·납품 확인서
  - 상품을 고르면 견적서 자동 계산, PDF/이미지로 저장해 카톡 전송
5단계 · 매출 대시보드
  - 이번 달 매출 / 1,000만 원 달성률 / 구독 고객 수 / 상담→계약 비율 / 영상 1편당 작업 시간
6단계 · 포트폴리오 페이지
  - 고객이 보는 소개 페이지(샘플 영상, 가격, 상담 신청서)

[작업 규칙]
1. 한 번에 한 단계만 만들고, 휴대폰 크기(390px)와 PC 크기에서 직접 눌러 본 뒤 올린다.
2. 고객 정보는 기기 안에만 저장하고 공개 저장소에 절대 올리지 않는다.
3. 다 하면 무엇이 바뀌었는지 쉽게 설명하고, 내가 직접 해 볼 순서를 1·2·3으로 알려 준다.
4. 뜻이 애매하면 만들기 전에 먼저 물어본다.
5. 다음 단계로 가기 전에 "이번 단계에서 고칠 점"을 나에게 물어본다.

[이번에 만들 단계]
(예: 1단계 · 고객/주문 관리)
```

## 7. 같이 일하는 방법 (Claude와 소통 규칙)

1. **한 번에 하나씩** — 큰 그림(1번) → 상품·가격 확정 → 샘플 영상 1편 → 프로그램 1단계 순서로 갑니다.
2. **결과를 보고 바로 말하기** — "이 장면은 너무 광고 같아", "가격이 비싸 보여"처럼 느낌 그대로 말하면 고칩니다.
3. **숫자는 매달 기록** — 5번 프롬프트로 월말 점검을 합니다.
4. **결정한 것은 이 파일에 적기** — 상품 이름·가격·타깃이 정해지면 0번 표를 실제 숫자로 바꿉니다.
