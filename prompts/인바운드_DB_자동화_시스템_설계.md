# 인바운드 DB 자동화 시스템 — 설계와 진행 현황

삼성생명 FC 현미숙 · HMS PREMIUM (2026-11-18 시작)

> 표시: ✅ 실제로 작동 · 🔶 일부 작동/사용자 설정 필요 · ⏳ 아직 안 만듦 · 💰 유료 서비스가 필요

## 1단계. 전체 구조 (설계)

```
고객 유입(블로그·쇼츠·인스타·카톡·QR·방문 안내문)
 → 상담 신청 홈페이지 apply.html (프로필·서비스 안내·신청서·동의)
 → 암호화해서 무료 Firebase '받은편지함'에 저장 (안 되면 고객 문자로 예비 접수)
 → 영업비서 앱이 열릴 때·2분마다 가져와 관심고객에 자동 등록 + 🔔 알림
 → 상담(통화 결과·약속) → 보장분석(고객 단계 '상담중') → 제안 → 계약 → 사후관리(유지관리)
```

| 부분 | 쓰는 도구 | 비용 |
|---|---|---|
| 앱·홈페이지 화면 | GitHub Pages (지금 주소) | 무료 |
| 휴대폰·태블릿 동기화, 상담 신청 받은편지함 | Firebase Firestore Spark 요금제 (이미 사용 중) | 무료 (하루 쓰기 2만 건 한도 안) |
| 신청 내용 보안 | 브라우저 암호화(RSA-OAEP + AES-GCM). 개인키는 FC 기기(암호화 동기화)에만 | 무료 |
| QR 코드 | 저장소의 qrcode.js (MIT) | 무료 |
| 앱이 완전히 꺼져 있을 때 휴대폰 푸시 알림 | Firebase Cloud Functions + FCM (Blaze 요금제) | 💰 (사용량이 적으면 거의 0원이지만 카드 등록 필요) |
| 자동 문자 발송(알림톡·문자 API) | 문자 발송 서비스 | 💰 건당 요금 |
| 진짜 AI 글쓰기(ChatGPT API 등) | 외부 AI API | 💰 + 개인정보 외부 전송 문제 → 지금은 앱 안 규칙·문구 틀 사용 |

## 2단계. 상담 신청 홈페이지 ✅
- apply.html: 히어로(30년 경력·개인사업자·자영업자·CEO), 프로필, 개인사업자 상담·자영업자 보장 점검·CEO 상담 안내, 무료 상담 신청서(성함·연락처·업종·지역·상담 희망 분야·연락 가능 시간·궁금한 점), 개인정보 수집·이용 안내 + [필수] 동의 + [선택] 마케팅 수신 동의, 신청 완료 화면, 모바일 최적화
- 🔶 개인정보 문구는 회사 준법감시 검토 후 확정 필요 (파일 안에 표시해 둠)

## 3단계. 고객 DB 자동 저장 🔶
- ✅ 고객이 신청 → 암호화되어 Firebase 받은편지함(hmsfc_in/{uid}/leads)에 저장 → 앱이 관심고객으로 자동 등록(출처 '상담신청·채널', 신청 날짜, 상담 희망 분야, 메모에 업종·지역·연락 가능 시간·문의·동의 기록) → 받은편지함에서 지움
- ✅ 중복 고객: 같은 전화번호면 새로 만들지 않고 메모에 '다시 상담 신청' 기록
- ✅ 예비: 저장이 안 되면 고객 휴대폰 문자로 접수 → 공유/붙여넣기로 등록
- 🔶 사용자 할 일: ① 앱 동기화 켜기(이미 켬) ② Firebase 콘솔 → Firestore → 규칙에 저장소의 firestore.rules 내용 붙여넣고 [게시] ③ 앱 DB자동발굴 → 상담 신청 페이지 → [📨 자동 접수 켜기] → 새 링크·QR 사용
- ⏳ 실제 Firebase로는 아직 시험 전(개발 환경에서 Firebase 접속이 막혀 있어 가짜 서버로 시험함)

## 4~7단계 — DB자동발굴 화면 안에 만듦 (홈은 그대로, 사용자 요청). 써 보고 필요 없는 칸은 지우기로 함
- 4 📊 영업 현황 ✅: 오늘 신규 DB · 전체 고객(고객+관심+CEO) · 상담 예정(약속잡음) · 미연락 고객(관심고객) · 보장분석 진행(고객 단계 상담중) · 제안 진행(제안) · 신규 계약(이번 달 실적 중 신계약) · 월간 상담 실적(미팅) · 월간 계약 실적(건수·보험료) · 후속 연락 예정(7일). 숫자를 누르면 명단(누르면 그 사람 창), 월간 상담은 목표 화면으로. 새 상담 신청 🔔 배너도 이 화면 맨 위(홈에는 안 띄움)
- 5 🤖 AI 영업비서 ✅ (앱 안 규칙, 외부 AI 안 씀): 📅 상담 일정(지난 연락일 + 오늘~7일 날짜별) · 📵 미상담 고객(상담 신청 먼저, 며칠째인지) · 📝 상담 준비·요약(7일 안 약속한 분 또는 이름 검색 → 단계·연락 상태·신청 메모·상담 횟수·최근 2번 기록·이번에 할 일 정리, 복사) · 🧭 다음 행동 추천(후속 상담 도우미) · 🏷️ 업종별 고객 분류(신청 업종 + 발굴 업종) · 📈 월간 실적 분석(이번 달 vs 지난달: 발굴·유입·상담 신청·신규 고객·미팅·계약·보험료, 목표 함께, 추천 한마디)
  - 신규 고객 자동 등록·신규 DB 알림은 3단계(자동 접수)로 됨
- 6 ✍️ 이번 주 콘텐츠 ✅: 주제 12개 중 주마다 3개 추천(다른 주제 모두 보기) → 📝 블로그 글 · 🎬 쇼츠 대본(40초) · 📸 인스타 · 💬 홍보 문구, 채널별 상담 신청 링크 자동 포함(유입 분석에 채널로 잡힘), 상품설명서·약관 안내 문구, 과장·가입 보장 약속 없이 '점검·준비' 위주. 🔶 올리기 전 회사 광고 심의 필요
- 7 알림 🔶: 앱을 열 때·열려 있으면 2분마다 확인 → 토스트·휴대폰 알림(허락 시)·NEW 표시 / 💰 앱이 꺼져 있을 때 푸시는 유료 서버 필요(미완성)
- 8 실제 작동 테스트 ⏳: Firebase 규칙 게시 → 자동 접수 켜기 → 사용자 휴대폰으로 신청 → 앱에 들어오는지 확인 (개발 환경에서는 가짜 서버로만 시험함)
- 9 설치 안내 ✅: 크롬으로 앱 설치(이미 설치함)
