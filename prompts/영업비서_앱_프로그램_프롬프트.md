## 2. 앱 개요

- 현미숙 FC 개인용 보험 영업관리 · 고객 소통 도우미
- 휴대폰은 앱처럼(홈 화면 설치, 아래 탭), PC·태블릿 가로 화면은 왼쪽 메뉴
- 서버 없이 동작하는 웹앱(PWA). 데이터는 각 기기 브라우저 안에 저장
- 핸드폰 · 태블릿은 Firebase로 자동 동기화(암호화)
- 첫 화면: 남색 바탕 HMS 로고(앱 열 때 1.2초), 아이콘: HMS / FC

### 홈 화면 세부 (지금까지 정한 모양)
- **인사 카드**: "안녕하세요, 현미숙 FC님" 아래에 **오늘의 확언 / 오늘의 한마디**가 날마다 바뀜(index.html의 `QUOTES` 목록, 누르면 다음 말)
- **정기 문자 칸**: 위에 두 칸으로 나란히
  - 왼쪽: [📝 월요일 인사문자 모음] → 상태 표시 → [✓ 보냈어요]
  - 오른쪽: [🧠 수요상식 문제 모음] → 상태 표시 → [✓ 보냈어요]
  - 수요상식 정답은 따로 칸 없이, 수요상식 문제 모음에서 문제 바로 밑에 '✅ 정답 문자 (오후 4시)'로 보임 (정답은 직접 복사해서 보냄, 따로 알람·보냈어요 없음)
  - 상태: 그날 시간 전 "오늘 08:30" / 시간 지났는데 안 보냄 "⏰ 08:30 보낼 시간!"(빨간색, 보낼 때까지 유지) / 보냄 "✓ 10/19 보냄"
  - 홈에 문구를 펼쳐 보이지 않음. 문구는 모음 버튼을 눌러 보고 복사(모음은 이번 주 문구로 자동 이동)
  - 월요일 08:30 인사문자, 수요일 13:30 수요상식 문제(정답 문자는 같은 날 16시쯤 모음에서 복사). 알람은 구글 캘린더/캘린더 파일(.ics)로 등록
- **생일 고객**: 생일 계절별 축하문자 자동 작성, 60세 이상은 "생신", 환갑 문구 없음, 다른 문구·복사·문자로 바로 보내기·보냈어요
- **교육 일정**: 예정 교육 D-day, 지난 교육은 홈에서 🗑 / 모두 삭제
- **이번 달 목표**: 오늘 할 일 위, 달성률 막대. 제목 옆 달 칸으로 다른 달 목표·실적도 보기(이번 달이 아니면 제목이 'N월 목표'), 목표 없으면 '목표 설정하기' → 목표 화면이 그 달로 열림. 목표 화면에서 목표 없는 달은 '📋 N월 목표 그대로 불러오기'(가장 가까운 지난달)
- **오늘 할 일**: 새로 적은 할 일은 맨 위에 들어감. 방금 네모칸을 체크해 매일 할 일이 된 것은 매일 할 일 중 맨 위로. 한 번짜리 할 일이 위, 🔁 매일 할 일이 아래(사용자 요청). 할 일마다 앞의 네모칸 = '매일 반복(고정)' 표시: 체크하면 🔁 매일 할 일(날마다 나옴), 풀면 한 번짜리 할 일(오늘)로. 글자를 짧게 누르면 글 고치기 창(입력 한 줄)만 뜸. 글자를 꾹(0.45초) 누르면 노랗게 들리고(진동) 손가락을 위아래로 움직여 순서 바꾸기(한 번짜리끼리·매일 할 일끼리, 끄는 동안 화면은 안 움직임, order 값으로 저장). 완료·순서 창은 복잡하다고 해서 뺌. 다 한 일은 ✕로 지우기(매일 할 일 ✕는 확인 창 후 그만하기). repeats[{id, text, created}], 제목 바로 옆에 날짜 칸, 직접 적기(날짜 지정 가능), 못 한 일은 "MM/DD부터"로 이어짐 + 오늘 연락할 고객 자동 목록
- **삭제 확인**: 고객·관심·가망·CEO·기계약자·삼성카드·삼성화재·교육·실적 창의 [삭제] → 앱 안 창으로 '김은하님을 삭제할까요?'(사람은 이름+님, 받침에 맞춰 을/를) [아니요]/[삭제] 한 번만 물어봄(두 번 묻기는 사용자 요청으로 뺌). [아니요]면 원래 창으로
- **☐ 가망 체크**: 고객·관심고객·CEO 목록에서 사람마다 별 옆 '☐ 가망' 칸 → 누르면 '☑ 가망'(초록) → 가망고객 화면 맨 위 '☑ 체크해서 온 가망고객'에 같이 보임(옮기지 않고 표시만, 누르면 원래 고객 창, 다시 누르면 빠짐, 검색도 됨). 그 아래 '🌱 가망고객'(원래 가망고객)
- **⭐ 중요고객** (예전 이름 관심고객 → DB고객이 관심고객이 되면서 바꿈): 고객·관심·가망·CEO 모두 별표 가능, 홈에 모아 보기

## 6. 동기화 (Firebase)

- 프로젝트: `hms-fc` (무료 Spark 요금제), Firestore 위치 asia-northeast3(서울)
