## 2. 앱 개요

- 현미숙 FC 개인용 보험 영업관리 · 고객 소통 도우미
- 휴대폰은 앱처럼(홈 화면 설치, 아래 탭), PC·태블릿 가로 화면은 왼쪽 메뉴
- 서버 없이 동작하는 웹앱(PWA). 데이터는 각 기기 브라우저 안에 저장
- 핸드폰 · 태블릿은 Firebase로 자동 동기화(암호화)
- 첫 화면: 남색 바탕 HMS 로고(앱 열 때 1.2초), 아이콘: HMS / FC

### 홈 화면 세부 (지금까지 정한 모양)
- **인사 카드**: "안녕하세요, 현미숙 FC님" 아래에 **오늘의 확언 / 오늘의 한마디**가 날마다 바뀜(index.html의 `QUOTES` 목록, 누르면 다음 말)
- **정기 문자 칸**: 위에 두 칸으로 나란히
  - 왼쪽: [📝 월요일 인사문자 모음] → 상태 표시 → [✓ 보냈어요]
  - 오른쪽: [🧠 수요상식 문제 모음] → 상태 표시 → [✓ 보냈어요]
  - 상태: 그날 시간 전 "오늘 08:30" / 시간 지났는데 안 보냄 "⏰ 08:30 보낼 시간!"(빨간색, 보낼 때까지 유지) / 보냄 "✓ 10/19 보냄"
  - 홈에 문구를 펼쳐 보이지 않음. 문구는 모음 버튼을 눌러 보고 복사(모음은 이번 주 문구로 자동 이동)
  - 월요일 08:30 인사문자, 수요일 13:30 수요상식. 알람은 구글 캘린더/캘린더 파일(.ics)로 등록
- **생일 고객**: 생일 계절별 축하문자 자동 작성, 60세 이상은 "생신", 환갑 문구 없음, 다른 문구·복사·문자로 바로 보내기·보냈어요
- **교육 일정**: 예정 교육 D-day, 지난 교육은 홈에서 🗑 / 모두 삭제
- **오늘 할 일**: 직접 적기(날짜 지정 가능), 체크·수정·삭제, 못 한 일은 "MM/DD부터"로 이어짐 + 오늘 연락할 고객 자동 목록
- **⭐ 관심고객**: 고객·DB·가망·CEO 모두 별표 가능, 홈에 모아 보기

## 6. 동기화 (Firebase)

- 프로젝트: `hms-fc` (무료 Spark 요금제), Firestore 위치 asia-northeast3(서울)
- 로그인: 구글 계정 (승인된 도메인에 `hms36903690.github.io` 등록됨)
- 저장 위치: Firestore `hmsfc/{uid}` 문서 하나 — 데이터는 **동기화 비밀번호**로 암호화(PBKDF2 → AES-GCM, gzip 압축)
- 홈 화면에 설치한 앱에서 구글 로그인 창이 안 뜨면 Chrome에서 로그인(같은 저장공간이라 앱에도 적용)
- 동기화 비밀번호를 잊으면 서버 데이터는 열 수 없음(기기 안 데이터는 남음)

## 8. 지금까지 정한 원칙 (사용자 선호)

- 쉬운 말로 설명, 바꾸기 전에 애매하면 확인
- 보험 영업 느낌 최소화, 50~70대도 읽기 쉬운 문구, 끝인사 "삼성생명 FC 현미숙 드림"
- 환갑 같은 나이 표현은 쓰지 않음
- 고객 정보·백업은 저장소에 올리지 않음. 저장소에는 앱 파일과 프롬프트만
- 실제 AI 연결(유료 API)은 아직 안 함 — 상담 문구는 문구 틀(템플릿) 방식
