# 현미숙 FC 영업비서 (2차 · 모바일 앱 버전)

보험설계사 현미숙 FC 개인용 영업관리·상담 도우미입니다.
휴대폰에서는 앱처럼, PC에서는 일반 웹 화면으로 씁니다.

## 기능

| 화면 | 할 수 있는 일 |
|---|---|
| 🏠 홈 | 오늘 연락할 고객, 7일 안에 생일인 고객, 이번 달 상담·계약 수, 목표 달성률을 봅니다. 백업을 오래 안 했으면 알려 줍니다. |
| 👥 고객 | 개인 고객을 등록하고 검색합니다(진행 단계별 보기). 전화·문자 버튼, 상담 기록, **상담 문구 만들기**가 있습니다. |
| 🏢 CEO | 법인 고객을 관리합니다. 가업승계·퇴직금 같은 관심 이슈를 체크하면 이슈별 제안 메모를 만들어 줍니다. |
| 🎯 목표 | 월별 목표(신규 고객, 상담, 계약, 월 보험료)를 정하면 달성률이 자동으로 계산됩니다. |
| 📊 실적 | 계약 실적을 입력하고 월별 합계를 봅니다. |
| ⚙️ 설정 | 내 이름, 백업 내보내기·불러오기, 전체 초기화 |

**상담 문구 만들기**는 미리 만든 문구 틀에 고객 정보를 채워 넣는 방식입니다.
외부 AI로 정보를 보내지 않으므로 무료이고, 고객 정보가 밖으로 나가지 않습니다.
문구 틀은 `index.html`의 `CUST_TEMPLATES`, `CEO_TEMPLATES` 부분에서 고칠 수 있습니다.

## 사용 방법

1. **바로 써 보기:** `index.html`을 Chrome으로 엽니다. 모든 기능이 동작합니다. 단, 앱 설치는 안 됩니다.
2. **휴대폰에 앱처럼 설치하기:** 아래 "인터넷에 올리기"를 한 뒤 휴대폰 Chrome으로 그 주소에 접속합니다. 메뉴(⋮)에서 **홈 화면에 추가** 또는 **앱 설치**를 누릅니다. 아이폰은 Safari의 공유(⬆) 버튼에서 **홈 화면에 추가**를 누릅니다.

### 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub 저장소에서 **Settings → Pages**로 들어갑니다.
2. Source를 `Deploy from a branch`로 바꾸고, 브랜치(예: `main`)와 `/ (root)` 폴더를 고른 뒤 Save를 누릅니다.
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.

> 올라가는 것은 앱 화면 파일뿐입니다. 고객 데이터는 각 기기에만 저장되고 인터넷에 올라가지 않습니다.
> 다만 GitHub 무료 계정은 저장소가 **공개(Public)**일 때만 Pages를 쓸 수 있습니다. 공개가 싫다면 Netlify나 Cloudflare Pages 같은 다른 무료 서비스를 쓸 수 있습니다.

### 새 버전을 올릴 때

`sw.js`의 `const CACHE = 'hmsfc-v2'` 숫자를 하나 올립니다(v3, v4 …).
그래야 휴대폰에 저장된 옛 화면이 새 화면으로 바뀝니다.

## 데이터와 백업 (중요)

- 데이터는 **그 기기의 그 브라우저 안(localStorage)**에만 저장됩니다.
- 브라우저 기록이나 사이트 데이터를 지우거나 휴대폰을 바꾸면 **데이터가 사라집니다.**
- ⚙️ 설정 → **백업 파일 내보내기**로 정기적으로 백업하세요. 홈 화면에서 14일마다 알려 줍니다.
- 휴대폰 ↔ PC로 옮길 때는 백업 파일을 내보낸 뒤 다른 기기에서 **백업 불러오기**를 합니다.

## 개인정보 주의

- 고객 정보는 어떤 서버로도 전송되지 않습니다.
- 휴대폰 화면 잠금을 꼭 사용하세요.
- 백업 파일에는 고객 정보가 그대로 들어 있습니다. 카톡이나 메일로 공유하지 마세요.
- 실제 업무에 쓰기 전에 회사의 개인정보·보안 규정을 확인하세요.

## 파일 구성

| 파일 | 역할 (쉬운 설명) |
|---|---|
| `index.html` | 앱 본체입니다. 화면, 모양(CSS), 동작(JavaScript)이 모두 들어 있습니다. |
| `manifest.json` | 앱 신분증입니다. 앱 이름, 아이콘, 색상을 적어 둡니다. 홈 화면에 설치할 때 사용됩니다. |
| `sw.js` | 서비스 워커, 휴대폰 안의 작은 관리인입니다. 앱 화면을 저장해 두어 인터넷이 없어도 열리게 합니다. |
| `icon.svg`, `icon-192.png`, `icon-512.png` | 앱 아이콘 |
