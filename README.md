# 현미숙 FC 영업비서 (2차 · 모바일 앱 버전)

보험설계사 현미숙 FC 개인용 영업관리·상담 도우미입니다.
휴대폰에서는 앱처럼, PC에서는 일반 웹 화면으로 씁니다.

## 기능

| 화면 | 할 수 있는 일 |
|---|---|
| 🏠 홈 | 오늘 연락할 고객, 7일 안에 생일인 고객, ⭐ 관심고객, 이번 달 상담·계약 수, 목표 달성률을 봅니다. 백업을 오래 안 했으면 알려 줍니다. |
| 👥 고객 | 개인 고객을 등록하고 검색합니다(진행 단계별 보기). 전화·문자 버튼, 상담 기록, **상담 문구 만들기**가 있습니다. |
| ⭐ 관심고객 | 고객·DB·가망·CEO 옆 ☆를 누르면 관심고객으로 표시됩니다. 목록 맨 위에 오고, 홈에도 모아서 보여 줍니다. 목록 위 ☆ 버튼으로 관심고객만 볼 수 있습니다. |
| 📥 DB고객 | 보험앱 등으로 들어온 신청 고객을 관리합니다. **받은 달별로 묶여서**(예: 2026년 10월 · 20명) 스크롤하며 볼 수 있고, 위쪽 월 버튼으로 바로 이동합니다. 달마다 미연락·부재·약속·고객 전환 수가 보입니다. 📋 버튼에 신청서 내용을 붙여넣으면 이름·연락처·나이·신청 내용을 자동으로 읽어 옵니다. 통화 결과 버튼(부재·통화완료·약속잡음·보류·거절)을 누르면 상태와 통화 횟수가 기록되고, 부재면 다음 날 재연락으로 잡힙니다. 새 DB(미연락)는 홈 '오늘 할 일'에 나옵니다. **고객 전환**으로 정식 고객으로 옮깁니다. |
| 🌱 가망고객 | 아직 상담 전인 분(소개받은 분, 지인)을 이름·연락처·소개자만 적어 둡니다. 첫 인사 문구를 만들 수 있고, 상담이 시작되면 **정식 고객으로 전환**을 누르면 고객 목록으로 옮겨집니다(상담 기록 포함). |
| 🏢 CEO | 법인 고객을 관리합니다. 가업승계·퇴직금 같은 관심 이슈를 체크하면 이슈별 제안 메모를 만들어 줍니다. |
| 📅 정기 문자 | 매주 보내는 문자(월요일 08:30 인사문자, 수요일 13:30 수요상식 문제)를 홈에 띄워 줍니다. 문구 복사 → 보내기 → ✓ 보냈어요. 아직 안 보낸 주는 '⏰ 08:30 보낼 시간!'으로 계속 알려 줍니다. **관리 · 알람**에서 구글 캘린더나 캘린더 파일(삼성 캘린더·아이폰)로 매주 반복 알람을 등록할 수 있습니다. |
| 📚 교육 일정 | 홈 화면에서 교육을 등록하고(날짜·시간·장소·준비물) 다가오는 교육을 D-day로 봅니다. 지난 교육은 홈 칸에서 🗑나 '모두 삭제'로 바로 지웁니다. 구글 캘린더 알람 등록 버튼이 있습니다. |
| 🎂 생일 축하문자 | 7일 안에 생일인 고객이 홈에 나옵니다. 누르면 생일 계절과 나이에 맞춘 축하문자가 자동으로 만들어집니다(60세 이상은 '생신'). '다른 문구'로 바꾸고, 복사하거나 문자로 바로 보낼 수 있습니다. 끝인사는 설정에서 바꿉니다. |
| ✏️ 오늘 할 일 | 홈 '오늘 할 일'에 직접 할 일을 적습니다. 날짜를 정하면 그날 나타나고, 못 한 일은 다음 날에도 'MM/DD부터'로 남습니다. 체크하면 줄이 그어지고, 글자를 누르면 고칠 수 있습니다. |
| 🎯 목표 | 월별 목표(신규 고객, 상담, 계약, 월 보험료)를 정하면 달성률이 자동으로 계산됩니다. |
| ⚙️ 설정 | 내 이름, 백업 내보내기·불러오기, 전체 초기화 |

**상담 문구 만들기**는 미리 만든 문구 틀에 고객 정보를 채워 넣는 방식입니다.
외부 AI로 정보를 보내지 않으므로 무료이고, 고객 정보가 밖으로 나가지 않습니다.
문구 틀은 `index.html`의 `CUST_TEMPLATES`, `CEO_TEMPLATES` 부분에서 고칠 수 있습니다.

## 사용 방법

1. **바로 써 보기:** `index.html`을 Chrome으로 엽니다. 모든 기능이 동작합니다. 단, 앱 설치는 안 됩니다.
2. **휴대폰에 앱처럼 설치하기:** 아래 "인터넷에 올리기"를 한 뒤 휴대폰 Chrome으로 그 주소에 접속합니다. 메뉴(⋮)에서 **홈 화면에 추가** 또는 **앱 설치**를 누릅니다. 아이폰은 Safari의 공유(⬆) 버튼에서 **홈 화면에 추가**를 누릅니다.

### 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub 저장소에서 **Settings → Pages**로 들어갑니다.
2. Source를 `Deploy from a branch`로 바꾸고, 브랜치(예: `main`)와 `/ (root)` 폴더를 고른 뒤 Save를 누릅니다.
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.

> 올라가는 것은 앱 화면 파일뿐입니다. 고객 데이터는 각 기기에만 저장되고 인터넷에 올라가지 않습니다.
> 다만 GitHub 무료 계정은 저장소가 **공개(Public)**일 때만 Pages를 쓸 수 있습니다. 공개가 싫다면 Netlify나 Cloudflare Pages 같은 다른 무료 서비스를 쓸 수 있습니다.

### 새 버전을 올릴 때

`sw.js`의 `CACHE` 숫자와 `index.html`의 `APP_VERSION`을 올립니다.
앱은 열거나 다시 볼 때 새 버전을 확인하고, 받으면 자동으로 한 번 새로고침합니다.
그래도 옛 화면이면 ⚙️ 설정 → **최신 버전으로 새로고침**을 누릅니다(고객 데이터는 지워지지 않음).

## 주차별 문구 모음 (`monday-messages.json`, `wednesday-messages.json`)

- `wednesday-messages.json`은 수요상식 퀴즈입니다. 지난주 정답을 다음 주 문자 첫머리에 알려 주는 방식입니다.
- 앱에서는 "11월 2주 수요일 (11/11)"처럼 그 달의 몇 번째 요일인지로 보여 줍니다.


- 그 주 월요일 날짜와 문구를 짝지어 적어 둔 파일입니다.
- 앱 홈의 **월요일 인사문자**는 이 파일에서 그 주 문구를 자동으로 꺼내 씁니다. 문구가 없는 주에는 앱에 직접 적어 둔 기본 문구를 씁니다.
- **관리 · 알람 → 월요일 인사문자 모음 보기**에서 한 달 치 문구를 미리 보고 복사할 수 있습니다.
- 매달 새 문구를 이 파일에 추가하면 됩니다. 앱을 다시 설치할 필요는 없습니다.

## ☁️ 핸드폰 · 태블릿 동기화 설정 (처음 한 번)

같은 구글 계정으로 로그인한 기기끼리 고객 정보가 자동으로 맞춰집니다.
데이터는 내가 정한 **동기화 비밀번호**로 잠근(암호화) 상태로만 서버에 올라가서, 비밀번호 없이는 누구도 내용을 볼 수 없습니다.

준비: 무료 구글 Firebase(구글의 앱용 저장 공간) 프로젝트 하나. **PC에서 하면 편합니다.** 약 10~15분.

1. **프로젝트 만들기**: https://console.firebase.google.com 접속 → 구글 로그인 → **프로젝트 만들기** → 이름 `hms-fc` → Google 애널리틱스는 **사용 안 함** → 만들기
2. **웹 앱 등록**: 프로젝트 첫 화면의 **`</>`(웹)** 아이콘 → 앱 닉네임 `영업비서` → (호스팅 체크 안 함) **앱 등록** → 화면에 나오는 `firebaseConfig = { apiKey: ..., authDomain: ..., projectId: ..., ... }` 부분을 복사해 둡니다.
3. **구글 로그인 켜기**: 왼쪽 메뉴 **빌드 → Authentication → 시작하기** → **로그인 방법** 탭 → **Google** → **사용 설정** 켜기 → 지원 이메일 선택 → 저장
4. **앱 주소 허용**: Authentication → **설정** 탭 → **승인된 도메인** → **도메인 추가** → `hms36903690.github.io` 입력 → 추가
5. **저장 공간 만들기**: 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 **asia-northeast3 (서울)** → **프로덕션 모드** → 만들기
6. **잠금 규칙 넣기**: Firestore Database → **규칙** 탭 → 내용을 모두 지우고 저장소의 `firestore.rules` 내용을 붙여넣기 → **게시**
7. **앱에 연결**: 2번에서 복사한 firebaseConfig를 앱 ⚙️ 설정 → **☁️ 핸드폰 · 태블릿 동기화** 칸에 붙여넣고 **연결 설정 저장**
   (또는 Claude에게 보내면 `sync-config.json`으로 넣어 두어, 모든 기기가 자동으로 연결 설정을 받습니다. 이 값은 비밀번호가 아니라 공개돼도 괜찮은 주소 정보입니다.)

### 기기마다 할 일
1. ⚙️ 설정 → **구글 계정으로 로그인** (핸드폰·태블릿 모두 **같은 구글 계정**)
2. 처음 기기: **동기화 비밀번호 만들기** (8자 이상, 두 번 입력) — **잊으면 서버 데이터를 열 수 없으니 꼭 적어 두세요.**
3. 두 번째 기기부터: 같은 동기화 비밀번호 입력 → 두 기기의 데이터가 **합쳐집니다** (어느 쪽도 지워지지 않음)

이후에는 앱을 열면 자동으로 맞춰지고, 한 기기에서 고친 내용이 몇 초 안에 다른 기기에도 반영됩니다.
같은 고객을 두 기기에서 고쳤다면 **더 나중에 고친 내용**이 남습니다.

## 데이터와 백업 (중요)

- 데이터는 **그 기기의 그 브라우저 안(localStorage)**에 저장됩니다. 동기화를 켜면 암호화된 사본이 Firebase에도 저장됩니다.
- 브라우저 기록이나 사이트 데이터를 지우거나 휴대폰을 바꾸면 **데이터가 사라집니다.**
- ⚙️ 설정 → **백업 파일 내보내기**로 정기적으로 백업하세요. 홈 화면에서 14일마다 알려 줍니다.
- 휴대폰 ↔ PC로 옮길 때는 백업 파일을 내보낸 뒤 다른 기기에서 **백업 불러오기**를 합니다.

## 개인정보 주의

- 고객 정보는 어떤 서버로도 전송되지 않습니다.
- 휴대폰 화면 잠금을 꼭 사용하세요.
- 백업 파일에는 고객 정보가 그대로 들어 있습니다. 카톡이나 메일로 공유하지 마세요.
- 실제 업무에 쓰기 전에 회사의 개인정보·보안 규정을 확인하세요.

## 파일 구성

| 파일 | 역할 (쉬운 설명) |
|---|---|
| `index.html` | 앱 본체입니다. 화면, 모양(CSS), 동작(JavaScript)이 모두 들어 있습니다. |
| `manifest.json` | 앱 신분증입니다. 앱 이름, 아이콘, 색상을 적어 둡니다. 홈 화면에 설치할 때 사용됩니다. |
| `sw.js` | 서비스 워커, 휴대폰 안의 작은 관리인입니다. 앱 화면을 저장해 두어 인터넷이 없어도 열리게 합니다. |
| `icon.svg`, `icon-192.png`, `icon-512.png` | 앱 아이콘 |
